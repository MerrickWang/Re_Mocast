# 作者确认清单（对应需求文档第 13 节）

下列信息部分已参数化，可通过 `mocast/configs/` 下的 YAML 调整；如果作者实现存在结构差异，仍需修改代码。
括号内为当前默认值与配置键。每一项确认都应记录在实验日志中；当前尚未完成 L4 数值复现，见 [已知问题](KNOWN_ISSUES.md)。

## 数据与预处理

1. SEVIR / MeteoNet / Shanghai 的精确训练/验证/测试划分，以及数据清洗与归一化参数。
   （通用配置采用事件级/文件级比例；当前 Shanghai 分组 H5 保留 test 组，从 train 组以 seed=2026 留出约 10% 验证集，实际为 1381/153/526；没有时间戳，不能保证事件独立。）
2. SEVIR 事件裁剪与缩放策略（是否中心裁剪 384²、缩放算法；建议 `area` / `bilinear`）以及空降水样本过滤阈值。
   （`dataset.crop`、`dataset.resize_mode`、`dataset.filter`）
3. MeteoNet 的区域筛选、缺测值策略（当前：`clip=[-10,70]`、非有限值填 0）与上海数据的公开获取方式、样本筛选规则。

## 模型结构

4. 局部注意力的 patch size、stride（是否重叠）、头数 K、嵌入维度 d_e，以及注意力缩放方式（`/√d_e` 还是 `/d_e`）。
   （`model.pmm.patch_size=4`、`window=3`、`heads=4`、`attn_dim=64`、`attn_scale=sqrt`）
5. 势函数通道定义（Φ 标量、ψ 是否标量）、离散梯度/旋度核与边界处理。
   （`kernel=central`、`padding=replicate`；2D 旋度取 `(∂ψ/∂y, −∂ψ/∂x)`）
6. DWT 小波基、分解层数、IDWT 时 LL 的处理方式、方向增强的精确公式（sigmoid 前是否含额外归一化）。
   （`basis=haar`、`levels=1`、`ll_mode=zero`、`enhance=sigmoid`）
7. MSM 三个尺度的卷积核/膨胀率、条件调制网络结构、门控网络的输入与输出粒度（逐位置还是逐区域）。
   （`kernels=[3,5,7]`、`dilations=[1,1,1]`、三组 γ/β 后线性投影、逐位置 softmax）
8. 时序预测网络的层数、隐藏维度、是否一次性输出 20 步（当前一次性；可选自回归），以及瓶颈投影通道数。
   （`model.temporal.embed_dim=64`、`num_blocks=2`、`prediction.mode=oneshot`）

## 平流与损失

9. 运动场单位（像素/归一化）、warp 方向（forward/backward flow）、`grid_sample` 参数
   （`align_corners`、`padding_mode`、插值方式）以及源汇项的数值尺度。
   （`unit=pixel`、`semantics=displacement`、`align_corners=true`、`mode=bilinear`、`padding_mode=border`）
10. 运动一致性损失的完整公式、降水掩码阈值 θ 与生成方式、是否 detach 目标分支、"avg" 的窗口大小。
    （`W=Binary[max(avg(X^t),avg(X^{t+1}))>θ]` → 平均池化到潜空间并保留覆盖率；`θ=dataset.motion_mask_threshold`；`detach_target=false`。2026-09-26 审查修复了重复平均损失和先 max 后 avg 的顺序，见 `Shanghai诊断与实现审查.md`。）

## 训练与扩散

11. AdamW 的 weight decay、early stopping patience、随机种子集合与 NNI 搜索空间。
    （`weight_decay=1e-2`、`patience=20`、`seeds=2026/2027/2028`）
12. MoCast+ 的扩散过程（DDPM/DDIM）、噪声调度与步数、残差定义（是否按验证集方差标准化）、条件注入方式。
    （`num_steps=1000`、`schedule=linear`、`residual_scale=1.0`、条件 = 基础预测 µ + 上下文帧）
