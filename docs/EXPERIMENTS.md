# Shanghai / RTX 5090 实验记录

更新：2026-09-27。数值来自维护者提供的 Linux 服务器运行输出；本地发布检查没有重新执行服务器训练。
原始 config、summary、权重和完整指标文件尚未入库，以下是转录记录，不是完整实验归档。

## 公共设置

- 数据：Mocast_shanghai.h5，train/test 分组，原 train 1534 个序列、test 526 个序列。
- 实际 train/val/test：1381/153/526；验证划分 seed=2026。
- 模型：MoCast，日志约 2.25 M 参数；5 帧输入、20 帧预测、128×128。
- 运行种子：2026；Linux / RTX 5090；BF16 AMP 训练。
- 当前配置：AdamW lr=1e-4、cosine、最多 200 epoch、val_csi 早停 patience=20。
- 编码暂按 pixel×70/255；阈值 [20,30,35,40] dBZ，名义帧间隔 6 分钟。
- 上述配置来自历史命令与本地预设；完整服务器快照和依赖版本仍应补存。

## 旧检查点的验证集诊断

使用修复后诊断工具加载旧检查点，默认 FP32、未校准：

| 分支 | CSI |

| persistence | 0.17227236210068994 |
| motion_only | 0.18194175759099576 |
| source_only | 0.15326704309783606 |

20 个预测步没有低于持久性基线的步。motion_only/source_only 是复用同一权重预测场的探测，不是重新训练消融。
训练内 best_score 与这里不同，还应考虑 AMP/FP32 口径。

算子探测：旧 BF16 零流 20 步 MSE=0.0030480418354272842，修复后=0；0.5 像素递推 20 次峰值=0.17619717121124268，单次 10 像素峰值≈1；正 dx 向右移动检查通过。
这些探测证明数值性质，不能单独量化真实雷达预测的损失来源。

旧模型验证集强度校准探索：系数 1.0/1.1/1.2/1.3/1.5 对应平均 CSI 0.2315/0.2587/0.2461/0.2292/0.2044。
1.1 为此次验证集最佳；没有对应的正式固定系数测试结果，未纳入上方测试表。

## H5 抽样审计

每 split 抽 32 个序列、每序列抽 5 帧统计像素；原值范围 train 0–236、val 0–209、test 0–211。
抽样精确序列重复和跨 split 非空帧重复均为 0；编码仍未自动确认。
在 pixel×70/255 假设下，本地验证抽样的 40 dBZ 覆盖率缩放前后为 0.1229% / 0.1173%，约减少 4.5%。
该抽样不是全量检查，也不证明无事件重叠。
